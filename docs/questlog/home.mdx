# How to read this documentation?

You should be familiar with JSON syntax to understand this documentation.
Every type has it's respective section in the documentation.<br />
Each section contains a description of the type, and a list of properties (if applicable) that the type has.

### Symbols
`|` basically means "or"; for example, [`Renderable`](./quest_definition#renderable) can be either a [`Texture`](./quest_definition#texture) or an [`Item`](#item).<br />
`[]` means that the type is an array;
for example, `Objective[]` is an array of [`Objective`](./quest_definition#objective) objects.<br />
`?` means that the property is optional;
for example, `translatable?: boolean` means that the `translatable` property is optional, and if not provided, the default value will be inferred.

Notice how these types have links. You can click on these links to jump to the respective section of the documentation.

## Loader compatibility for Minecraft 1.21.1

This branch targets Minecraft **1.21.1**. The minimum loader versions are:

| Loader | Minimum version |
| --- | --- |
| NeoForge | 21.1.80 |
| Fabric Loader | 0.15.11 |

These are metadata minimums, not a requirement to install the newest loader release.
Other mods in a pack can require a newer version. Fabric also requires Fabric API;
the Triggers library is bundled in the supported builds. Minecraft 1.21.1 is supported
through NeoForge and Fabric.
See `LOADER_COMPATIBILITY.md` in the repository for the dependency reasons, build properties
and recorded compilation checks.
